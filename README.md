# CPU Scheduling Simulator (SJF vs Priority) 🚀

This project is a comprehensive simulator designed to compare **Shortest Job First (SJF)** and **Priority Scheduling** algorithms (both Preemptive and Non-Preemptive).

## 📂 Project Structure
- `src/`: Contains the core Python logic and Streamlit UI.
- `web_version/`: An alternative implementation using HTML/CSS/JS.
- `assets/screenshots/`: Visual demonstration of the tool.
- `test-cases/`: Pre-defined scenarios used for validation.
